# Worodoro ⏱️

**Worodoro** is a productivity-focused mobile application inspired by the classic Pomodoro technique. It enhances time management by combining task tracking, customized intervals, and progress insights — helping users stay focused and reduce burnout.

## 🚀 Features

- ⏳ **Customizable Work/Break Timers** – Tailor your focus and rest periods to match your workflow.
- 🗂️ **Task Management** – Organize your tasks and associate them with Pomodoro sessions.
- 📈 **Progress Tracking** – Visualize your completed sessions and task completion stats.
- 🔔 **Smart Notifications** – Alerts for start/end of sessions and breaks.
- 🌓 **Dark Mode Support** – Reduce eye strain with a clean, user-friendly interface.
- 📱 **Cross-platform Mobile Support** – Runs smoothly on both Android and iOS.

## 🛠️ Tech Stack

- **Flutter** – UI development
- **Dart** – Application logic
- **Firebase** – (Optional) For authentication or syncing
- **Hive / SQLite** – Local data persistence
